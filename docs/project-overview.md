# FitOps

## Project Overview

FitOps is a modern Gym Management System built as a production-quality portfolio project.

## Tech Stack

Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

Backend
- Laravel 12
- Sanctum Authentication
- Spatie Laravel Permission

Database
- MySQL

## Roles

- Admin (Gym Owner)
- Trainer
- Member
