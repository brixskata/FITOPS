# FitOps Development Rules

General

- Never redesign the UI unless requested.
- Always reuse existing components.
- Keep components reusable.
- Keep code modular.
- Follow Laravel 12 best practices.
- Follow React best practices.

Frontend

- React
- Tailwind CSS
- Axios
- React Router

Backend

- Laravel 12
- Sanctum
- Spatie Permission

Database

- MySQL

Design

- Modern
- Premium
- Minimal
- Responsive

Never

- Use Bootstrap
- Duplicate components
- Duplicate API logic
- Mix API logic inside UI components

Always

- Create reusable components.
- Create reusable services.
- Keep pages clean.
