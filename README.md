# 🏋️ FitOps

A modern full-stack Gym Management System built with React, Laravel 12, Sanctum, and MySQL.

## 🚀 Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend

- Laravel 12
- Sanctum Authentication
- Spatie Laravel Permission
- MySQL

## ✨ Features

- Responsive Landing Page
- Authentication
- Role-Based Access (Admin, Trainer, Member)
- Members Management
- Membership Plans
- Attendance
- Payments
- Equipment Management
- Reports
